# - Protected routes (JWT required)
# - Logout (token blacklist)


# =====================================================
# 🔹 2. API DESIGN (PRODUCTION THINKING)
# =====================================================

# APIs are structured using clean architecture:

# Routes Layer:
# - Handles request/response
# - Validates input
# - Calls service layer

# Service Layer:
# - Contains business logic
# - Handles DB operations
# - Handles edge cases (duplicate users)

# Model Layer:
# - Defines DB schema
# - Includes password hashing methods

# This separation is industry standard.


# =====================================================
# 🔹 3. EDGE CASES HANDLED
# =====================================================

# We handled important real-world scenarios:

# ✔ Duplicate email registration
#   → Handled using DB constraint + IntegrityError

# ✔ Invalid login
#   → Returns 401 (Unauthorized)

# ✔ Protected route without token
#   → Blocked using @jwt_required()

# ✔ Logout
#   → Token stored in blocklist (JWT invalidation)

# ✔ Password hashing
#   → Secure storage using werkzeug
