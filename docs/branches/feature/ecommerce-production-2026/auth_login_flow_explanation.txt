----------------------------------------
LOG:
"POST /api/v1/auth/angularUser/login HTTP/1.1" 200

- Angular app sent login request with credentials
- Endpoint:
    /api/v1/auth/angularUser/login

STEP 4: AUTHENTICATION SUCCESS
----------------------------------------
LOG:

[REQ:addd70cf-8695-4b4f-bb0b-bd4b4c3c45c1]

- user_id=6 → User found in DB and authenticated successfully

Internally this means:
✔ User credentials verified
✔ Password matched (bcrypt)
✔ JWT token generated
✔ Response returned to frontend

----------------------------------------
Status:
200 OK

Frontend receives:
- Access Token (JWT)

- User details (optional)
