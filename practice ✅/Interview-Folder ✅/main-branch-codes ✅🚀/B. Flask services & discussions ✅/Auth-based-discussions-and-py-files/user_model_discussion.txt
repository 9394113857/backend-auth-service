✅ Q19:
“Why store tokens in blocklist?”

Answer

JWT is stateless. **** 

After logout:

1.	token still remains valid until expiry.
2.	Blocklist helps invalidate tokens before expiration.


✅ Q20:
“Why index=True on jti?”

Answer

1.	Creates database index.
2.	Improves token lookup performance.

Important because:

1.	every request may check blacklist.

✅ Q21:
“How logout works with JWT blocklist?”

Answer

1.	User logs out.
2.	Token jti stored in blocklist table.
3.	Future requests check blocklist.
4.	If jti exists → token rejected.

4.	hashing cannot.
