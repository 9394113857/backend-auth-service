🔷 ANGULAR PROJECT STRUCTURE – Interview Questions & Answers
✅ src/styles.css
Q1:
“What is styles.css in Angular?”
Answer

Global stylesheet for Angular application.

Applies styles across entire application.

Q2:
“Difference between component CSS and styles.css?”
Answer

Component CSS:

local styles

styles.css:

global styles
Q3:
“What kind of styles usually placed in styles.css?”
Answer

Examples:

global themes
Bootstrap imports
body styles
reusable utility classes
