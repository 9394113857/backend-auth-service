🔷 ANGULAR INTERVIEW QUESTIONS & ANSWERS
✅ 1. Angular
Q1:
“What is Angular?”
Answer

Angular is TypeScript-based frontend framework developed by Google.

Used for:

Single Page Applications (SPA)
dynamic frontend applications
component-based architecture
Q2:
“Why Angular used?”
Answer

Benefits:

reusable components
routing
dependency injection
modular architecture
strong TypeScript support
Q3:
“What is SPA?”
Answer

Single Page Application.

Page reload not required for every request.

Angular dynamically updates UI.

Q4:
“What is component in Angular?”
Answer

Reusable UI building block.

Contains:

HTML
CSS
TypeScript logic
Q5:
“What is module in Angular?”
Answer

Groups related Angular functionality.

Example:

AppModule
feature modules

Q32:

Answer

Q33:

Answer

Supports SPA navigation without full page reload.

Q34:

Q35:

Answer

Improves:

performance
initial load speed
Q36:

Answer

routerLink:

href:
full page reload
