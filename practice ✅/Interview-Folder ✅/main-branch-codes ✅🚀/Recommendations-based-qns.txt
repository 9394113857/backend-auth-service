✅ Q1:
“What is Recommendation Service?”
Answer

Serves personalized product recommendations to users.

Reads precomputed ML recommendation results from database and returns ranked products.

✅ Q2:
“Why separate Recommendation Service?”
Answer

Separates:

Improves:

scalability

independent deployment
