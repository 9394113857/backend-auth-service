🔷 YAML QUESTIONS (VERY IMPORTANT)
✅ Q1:
“What is YAML?”
Answer

YAML is human-readable configuration language.

Used heavily in:

DevOps
CI/CD
Kubernetes
Docker Compose
cloud configurations
✅ Q2:
“What is full form of YAML?”
Answer

Originally:
Yet Another Markup Language

Now officially:
YAML Ain’t Markup Language

✅ Q3:
“Why YAML popular in DevOps?”
Answer

Because YAML is:

simple
readable
structured
easy for configuration management
✅ Q4:
“Is YAML programming language?”
Answer

No.

YAML is configuration/data serialization language.

Used for defining:

workflows
deployments
infrastructure configs
✅ Q5:
“Why indentation important in YAML?”
Answer

YAML uses indentation to define hierarchy.

Wrong indentation causes parsing errors.

✅ Q6:
“Difference between YAML and JSON?”
Answer

YAML:

more readable
supports comments
DevOps-friendly

JSON:

stricter syntax
commonly used in APIs
✅ Q7:
“What is YAML syntax mainly used for?”
Answer

Defining structured configurations.

Examples:

CI/CD pipelines
Kubernetes deployments
cloud infrastructure

Answer

Defines workflow trigger.

push

workflow_dispatch
schedule
✅ Q14:
“What is jobs: section?”

Defines CI/CD tasks to execute.

✅ Q15:
“What is steps: section?”
Answer

Defines ordered execution steps.

Example:

checkout code
install dependencies
deploy app
